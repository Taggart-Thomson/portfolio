# Messaging workflow automation

## What Taggart runs

Every term, Taggart rebuilds and launches 9 messaging workflows in HubSpot, a marketing automation platform. Once live, enrollment and sends run automatically.

## How they work

The workflows use triggered sends and HTML-built emails. A webinar integration enrolls every member automatically, so nobody has to be added by hand.
